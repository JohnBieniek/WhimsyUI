# Whimsy Facebook media context catalog

Open `index.html` in a browser. It contains 852 indexed media files, 2 unique hosted-event records, campaign group pages, a CSV inventory, and a watermark review page.

## Interpretation

- **Promotion** means the caption or description contains invitation, schedule, giveaway, opening, or event language.
- **Result** means the post explicitly describes attendance, thanks attendees, or recaps an event.
- **Context** means the item belongs to the topic group but is not confidently an advertisement or result photo.
- Event relationships are inferred from explicit caption terms and dates. They are not presented as confirmed when the export does not supply a direct event identifier.
- `watermarks.html` contains images where OCR found “Whimsy” in the upper or lower third. Subtle graphic marks may require manual review.
